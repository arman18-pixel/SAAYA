# 🛡️ SAAYA — Your Invisible Safety Companion

SAAYA is a women safety application prototype designed to provide discreet and intelligent emergency assistance when a user may not be able to physically operate her phone.

## 💡 Overview

SAAYA allows the user to create a personalized emergency code word and register her voice. When the code word is detected, the app provides a **10-second cancellation window** in case of an accidental trigger.

If the user does not cancel, SAAYA proceeds with **speaker verification**. Once the code word and registered speaker are verified, the emergency is treated as a **Verified Emergency**.

The app then uses contextual information to determine the **priority of escalation**, while ensuring that contextual scoring never cancels a verified emergency.

## 🧠 Our Key Innovation

SAAYA does not depend on movement, nighttime conditions, or a danger score to decide whether a user needs help.

The principle is:

> **Verify first. Escalate with context.**

Once a user's emergency request is verified, contextual signals are used only to determine the level of response.

> **Context can increase priority, but it can never cancel a verified emergency.**
